# Conciso — платформа против речевой избыточности

Проверка текста на плеоназмы, тавтологию, канцеляризмы и слова-паразиты (до 2000 слов), игры, картотека с интервальными повторениями, исследовательский «Корпус» и страница «Ясность и точность»: оценка ясности текста, исправленный вариант и измерение качества проверки. Работает без сервера и без интернета; прогресс хранится в браузере и переносится зашифрованным кодом `CNC3:`.

## Запуск
Положите файлы в корень репозитория и включите GitHub Pages (ветка `main`, папка `/`):
`index.html`, `dictionary.json`, `sw.js`, `manifest.webmanifest`, `icon.svg`.

## Как устроена проверка
1. Словарь (около 1000 записей, встроен в `index.html`, дополняется строками из `dictionary.json`).
2. Шаблоны: формы слов, названия месяцев, направления, степени сравнения, «пустой глагол + существительное».
3. Морфология: слова сравниваются по основам, поэтому находятся любые падежи, числа и времена; допускается вставка слов между частями оборота и обратный порядок слов.
4. Кластеры синонимов (например «новые свежие идеи») и однокоренные слова рядом.
Основная проверка считается на устройстве: без лимитов и без отправки текста.

## Локальный ИИ (необязательно)
Вкладки настройки нет: сайт сам ищет на вашем компьютере Ollama (порт 11434), LM Studio (1234), llama.cpp (8080) или vLLM (8000) и выбирает модель Qwen, если она установлена. Текст уходит только на ваш компьютер.
Пример для Ollama: `ollama pull qwen2.5:7b`, затем запуск `OLLAMA_ORIGINS=* ollama serve`. Адрес в локальной сети работает на портах 11434, 1234, 8080 и 8000 (так задано политикой CSP в `index.html`). Другой адрес: откройте сайт со строкой `?ai=http://192.168.1.5:11434&model=qwen2.5:7b`.
Если сервер не найден, проверка работает по словарю и правилам словоформ. Каждая находка ИИ принимается, только если фрагмент дословно есть в вашем тексте.

## Как добавить правило
В `dictionary.json` добавьте `{"t":"p","bad":"свободная вакансия","good":"вакансия","why":"вакансия уже означает свободное место"}`. Типы: `p` плеоназм, `t` тавтология, `k` канцеляризм, `w` слово-паразит, `s` штамп, `g` лишняя степень сравнения. Затем проверьте результат в разделе «Ясность и точность»: вставьте свои размеченные фразы в формате `фраза | 1` или `фраза | 0`.


## Ясность и точность (одна функция)
Одно поле, одна кнопка «Проанализировать». Сайт сам определяет режим:
- **Текст** (от 15 слов): оценка ясности 0–100, найденная избыточность с пометкой «спорно», длинные предложения и сложные слова, исправленный вариант с оценкой «было → стало».
- **Размеченные фразы** (от 6 строк вида `фраза | 1` / `фраза | 0`): полнота, точность, F1 и доля верных ответов самого сайта, списки пропусков и ложных тревог.

Оценка ясности: читаемость по Оборневой 45%, избыточность 25%, длина предложений 20%, сложные слова 10%.

## Профиль и безопасность
Серверных аккаунтов нет, поэтому нет и того, что можно взломать или утечь: ни паролей, ни почты, ни телефонов. Профиль — это псевдоним и аватар в браузере. Сейф удалён.
- **Регистрация.** Псевдоним 2–20 знаков (буквы, цифры, пробел, дефис), без фамилии. При создании профиля браузер генерирует пару ключей ECDSA P-256; закрытый ключ хранится в IndexedDB как неизвлекаемый и не покидает устройство.
- **Рейтинг класса.** Код `CL2:` подписан ключом профиля. Изменить имя или баллы в чужом коде нельзя: подпись перестаёт сходиться, код отклоняется. Старые коды `CL1:` не принимаются, потому что их можно подделать. Ученики в таблице различаются по короткому ID ключа.
- **Перенос на другое устройство.** Код `CNC3:` шифруется AES-256-GCM одноразовым ключом из 20 знаков (100 бит, PBKDF2 200 000 шагов), действует 15 минут, при расшифровке данные проверяются и ограничиваются. Код и ключ передают разными способами.
- **Что защитить нельзя.** Сайт без сервера не может помешать ученику накрутить баллы на своём устройстве: для этого нужен сервер. Подпись защищает только код при пересылке. Это стоит указать в защите проекта как ограничение.

## Ограничения
Проверка не понимает смысл: скрытые плеоназмы и спорные случаи возможны. Точность нужно измерять на своих данных.
